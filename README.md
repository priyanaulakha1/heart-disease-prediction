# ❤️ Heart Disease Prediction

## 📌 Overview

This project predicts the possibility of heart disease using a trained Logistic Regression model. It provides an interactive web interface built with Streamlit where users can enter health-related information and receive a prediction.

## ✨ Features

- Interactive web application
- Logistic Regression model for prediction
- Saved model and scaler files
- Input feature column management
- User-friendly interface built with Streamlit

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Joblib
- Jupyter Notebook

## 📂 Project Structure

```text
heart-disease-prediction/
├── app.py
├── LR_heart.pkl
├── scaler.pkl
├── columns.pkl
├── heart.csv
├── heart.ipynb
├── requirements.txt
└── README.md
```

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/priyanaulakha1/heart-disease-prediction.git
cd heart-disease-prediction
```

### 2. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
streamlit run app.py
```

The application will open in your browser, usually at `http://localhost:8501`.

## 🎯 Project Objective

The objective is to make a Machine Learning prediction model accessible through a simple, interactive web application.
